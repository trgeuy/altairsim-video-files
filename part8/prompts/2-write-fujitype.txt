Write a new FujiNet tool for CP/M called FUJITYPE. It prints a text file on the FujiNet's printer, so that FUJITYPE NOTES.TXT gives the same text as TYPE NOTES.TXT, but on paper. Follow the style of the tools in Reference/FujiNet-CPM-Tools: the same usage message when there is no argument, and a clear message when something goes wrong. Call it FUJITYPE v1.0. Build it with ASM and LOAD on the Altair, and test it with FujiNet-PC. There is a known issue with FujiNet's PDF printers (fujinet-firmware issue #2043): the printer starts a new page only between two WRITE packets, so lines can print below the bottom of the page. Work around it: send one printed line in each WRITE. When a line is longer than 80 characters, split it: send a CR LF after each 80 characters, and print the rest of the line on the next printed line. Do not drop any characters. Make one of your test files longer than one page, with at least one line longer than 80 characters.
